# Israel election 2026 - live results feed

`results.json` is the data file behind the live TerraExplorer Fusion map of the Knesset election on 27.10.2026.
It is rewritten automatically from the Central Elections Committee's published results and served with GitHub Pages.
No polls or partial results are published before the polls close at 22:00.

Sources: Central Elections Committee (votes26.bechirot.gov.il), data.gov.il, OpenStreetMap contributors.
